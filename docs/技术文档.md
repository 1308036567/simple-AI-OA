## 🎯 系统概述

### 技术架构
- **后端**: FastAPI + SQLAlchemy + MySQL
- **前端**: Vue3 + Vant + Axios
- **AI模型**: ChatGLM-6B (本地部署)
- **语音处理**: Vosk语音识别 + pyttsx3语音合成
- **数据安全**: AES加密 + 操作日志
- **部署方式**: 本地服务器 + FRP内网穿透

### 核心特性
- 移动端优先设计
- AI语音交互
- 敏感数据加密
- 自动备份机制
- Excel批量处理
- 实时图表生成

## 🗄 数据库设计

### 1. 表结构设计

#### 1.1 员工表 (employees)
```sql
CREATE TABLE employees (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL COMMENT '姓名',
    id_card BLOB NOT NULL COMMENT '身份证号(加密)',
    phone VARCHAR(20) NOT NULL COMMENT '手机号',
    bank_card BLOB COMMENT '银行卡号(加密)',
    bank_name VARCHAR(100) COMMENT '开户行',
    is_archived BOOLEAN DEFAULT FALSE COMMENT '是否归档',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_name (name),
    INDEX idx_phone (phone),
    INDEX idx_archived (is_archived)
);
```

#### 1.2 文件记录表 (file_records)
```sql
CREATE TABLE file_records (
    id INT AUTO_INCREMENT PRIMARY KEY,
    filename VARCHAR(255) NOT NULL COMMENT '存储文件名',
    original_filename VARCHAR(255) NOT NULL COMMENT '原始文件名',
    file_path VARCHAR(500) NOT NULL COMMENT '文件路径',
    file_size INT NOT NULL COMMENT '文件大小',
    file_type VARCHAR(50) NOT NULL COMMENT '文件类型',
    category VARCHAR(50) NOT NULL COMMENT '文件分类',
    business_id VARCHAR(100) COMMENT '关联业务ID',
    description TEXT COMMENT '文件描述',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    INDEX idx_category (category),
    INDEX idx_business_id (business_id)
);
```

#### 1.3 账表主表 (account_tables)
```sql
CREATE TABLE account_tables (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(200) NOT NULL COMMENT '账表名称',
    table_type VARCHAR(50) NOT NULL COMMENT '账表类型',
    description TEXT COMMENT '账表描述',
    file_path VARCHAR(500) COMMENT '生成文件路径',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_type (table_type)
);
```

### 2. 数据关系

```
employees (员工表)
    ↓ 一对多
salary_records (工资记录表)
    ↓ 多对一
account_tables (账表主表)
    ↓ 一对多
expense_records (支出记录表)

file_records (文件记录表)
    ↓ business_id关联
```

### 5. 前端集成示例

#### 5.1 Vue组件示例
```vue
<template>
  <div class="employee-management">
    <van-search
      v-model="searchQuery"
      placeholder="搜索员工"
      @search="searchEmployees"
    />
    
    <van-list
      v-model:loading="loading"
      :finished="finished"
      @load="loadEmployees"
    >
      <van-cell
        v-for="employee in employees"
        :key="employee.id"
        :title="employee.name"
        :label="employee.phone"
        @click="viewEmployee(employee)"
      />
    </van-list>
    
    <van-floating-bubble
      icon="plus"
      @click="addEmployee"
    />
  </div>
</template>

<script>
export default {
  data() {
    return {
      employees: [],
      searchQuery: '',
      loading: false,
      finished: false
    };
  },
  methods: {
    async loadEmployees() {
      const response = await this.$http.get('/api/employees', {
        params: {
          skip: this.employees.length,
          limit: 20,
          search: this.searchQuery
        }
      });
      
      this.employees.push(...response.data);
      this.loading = false;
      
      if (response.data.length < 20) {
        this.finished = true;
      }
    }
  }
};
</script>
```
